# 荣格斯二代16功能-64型人格评价系统理论文档

## 1. 理论概述

### 1.1 荣格斯第二代认知功能理论

本项目采用**荣格斯第二代认知功能体系**（JUNGUS 2nd Generation），这是对传统荣格八维理论的扩展和深化。

**核心创新：**
- 原始8个荣格认知功能，每个分化为2个子形态（亚型）
- 共计16个细分认知功能
- 基于主导+辅助细分功能组合，推导出64种人格原型

**与传统MBTI的区别：**
- 传统MBTI：4个维度 → 16种类型
- 荣格八维：8个认知功能 → 16种类型
- **荣格斯二代：16个细分功能 → 64种类型**

### 1.2 16细分认知功能定义

#### 感觉功能（Se）分化
1. **Se-探索型 (SE_EXPLORATORY)**  
   主动探索环境，寻求新奇的感官体验，喜欢冒险和即时行动

2. **Se-稳定型 (SE_STABILIZING)**  
   享受当下的感官体验，倾向于维持熟悉的环境和节奏

#### 内倾感觉（Si）分化
3. **Si-回忆型 (SI_RECOLLECTIVE)**  
   调取过去经验和记忆，通过对比历史数据来指导当前决策

4. **Si-稳态型 (SI_HOMEOSTATIC)**  
   维护内部稳定和秩序，遵循既定程序和传统方法

#### 外倾直觉（Ne）分化
5. **Ne-发散型 (NE_DIVERGENT)**  
   头脑风暴式思维，探索多种可能性，喜欢发散性思考

6. **Ne-整合型 (NE_INTEGRATIVE)**  
   连接看似无关的概念，发现隐藏的联系和模式

#### 内倾直觉（Ni）分化
7. **Ni-预见型 (NI_PROPHETIC)**  
   预见未来趋势和结果，洞察事物本质，形成远见

8. **Ni-综合型 (NI_SYNTHESIZING)**  
   整合复杂信息为统一愿景，形成深层洞察

#### 外倾思考（Te）分化
9. **Te-执行型 (TE_EXECUTIVE)**  
   组织资源追求效率，建立秩序和标准，注重执行力

10. **Te-实证型 (TE_EMPIRICAL)**  
    依赖数据和实证验证，建立标准化流程和系统

#### 内倾思考（Ti）分化
11. **Ti-分析型 (TI_ANALYTICAL)**  
    逻辑推理和分析，构建内部概念框架，追求理解

12. **Ti-精确型 (TI_PRECISION)**  
    追求概念精确和逻辑一致，消除矛盾和模糊

#### 外倾情感（Fe）分化
13. **Fe-和谐型 (FE_HARMONIZING)**  
    维护群体和谐，照顾他人情感需求，促进团结

14. **Fe-影响型 (FE_INFLUENCING)**  
    引导和影响群体情感，塑造氛围和价值观

#### 内倾情感（Fi）分化
15. **Fi-真实型 (FI_AUTHENTICATING)**  
    追求内在真实，坚守个人价值观和道德准则

16. **Fi-个体型 (FI_INDIVIDUATING)**  
    探索自我身份，深化个人情感体验和意义

### 2.2 权重配置

所有行为事件的权重系数保存在 `personality_64/behavior_weights.gd` 中，可以独立调整。

**权重示例（冲锋攻击）：**
```gdscript
EVENT_CHARGE_ATTACK: {
    SE_EXPLORATORY: 8.0,   # 探索型享受冲锋刺激
    NE_DIVERGENT: 3.0,     # 发散型喜欢即兴行动
    TE_EXECUTIVE: 2.0,     # 执行型快速决策
    FI_INDIVIDUATING: -2.0 # 个体型倾向内省而非冲动
}
```

## 3. 无线电对话与认知功能映射

### 3.1 对话节点设计

每个对话节点包含2-4个选项，每个选项绑定若干16细分功能的权重加成。

**对话示例（波次1后）：**
```
指挥官：干员，第一波敌人已清除。前方侦察显示有更强的敌军集结。你建议如何推进？

选项1：立即突击，趁他们还没完全集结
  → Se探索 +8, Ne发散 +4, Te执行 +3

选项2：先侦察敌情，制定详细计划再行动
  → Ni预见 +7, Ti分析 +5, Si回忆 +3

选项3：呼叫支援，等待增援到达
  → Fe和谐 +6, Si稳态 +4, Te实证 +3

选项4：绕到侧翼，寻找薄弱点突破
  → Ne整合 +6, Ne发散 +5, Ti分析 +4
```

### 3.2 对话配置

所有对话节点保存在 `scenario/dialogue_manager.gd` 中，可以独立编辑和扩展。

## 4. 计分与归一化

### 4.1 数据采集

**双数据源：**
1. **战斗行为数据（60%权重）**：通过 `PersonalityTracker.record_battle_event()` 记录
2. **对话选择数据（40%权重）**：通过 `PersonalityTracker.record_dialogue_choice()` 记录

**权重参数可修改：**
```gdscript
const BATTLE_WEIGHT := 0.6   # 战斗行为数据权重
const DIALOGUE_WEIGHT := 0.4 # 对话选择数据权重
```

### 4.2 归一化公式

对每个数据源分别归一化到0-100区间：

```
normalized_score[func_id] = (raw_score[func_id] / max_raw_score) * 100.0
```

### 4.3 加权合并

```
final_score[func_id] = normalized_battle[func_id] * 0.6 + normalized_dialogue[func_id] * 0.4
```

### 4.4 功能排序

对16个细分功能的最终分数降序排序，选出：
- **主导功能**（第1名）
- **辅助功能**（第2名）
- **第三功能**（第3名）
- **第四功能**（第4名）

## 6. 权重参数调参指南

### 6.1 可调参数位置

1. **数据源权重**：`personality_64/personality_tracker.gd`
   ```gdscript
   const BATTLE_WEIGHT := 0.6   # 战斗行为数据权重
   const DIALOGUE_WEIGHT := 0.4 # 对话选择数据权重
   ```

2. **行为事件权重**：`personality_64/behavior_weights.gd`
   - 每个行为事件对16功能的加成系数
   - 可以调整正负权重来改变行为倾向

3. **对话选项权重**：`scenario/dialogue_manager.gd`
   - 每个对话选项对16功能的加成系数
   - 可以调整权重来改变对话选择的影响

### 6.2 调参建议

- **增加某功能的权重**：让更多行为事件对该功能加分
- **减少某功能的权重**：降低相关事件的加分或增加负权重
- **平衡数据源**：调整 BATTLE_WEIGHT 和 DIALOGUE_WEIGHT 的比例
